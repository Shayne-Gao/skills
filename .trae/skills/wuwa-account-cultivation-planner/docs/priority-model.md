# Priority Model

## Goal

Define how the skill should think about cultivation priority before it gives account-specific advice.

This model has two layers:
1. current-version team / role priority
2. per-character growth-factor priority

## Layer 1: Current-Version Team / Role Priority

When evaluating what to cultivate first, use this order:

### Priority A: Top Current-Version Teams

Highest priority goes to:
- teams that are currently top-tier in the version
- teams already close to completion on the account
- teams with strong support + weapon alignment already present

These should usually receive the first serious investment.

### Priority B: High-Potential Key Roles

Second priority goes to:
- high-potential key roles that can become account anchors
- newly released or current-version standout roles
- roles that unlock multiple future team branches

These may outrank older full teams if their future value is much higher, but only when the account can realistically support them.

### Priority C: Older-Version Teams

Last priority goes to:
- older teams with weaker current retention
- fallback teams that are playable but not the strongest account growth path
- filler or transitional investments

These are still useful, but should usually not consume the first wave of scarce resources.

## Layer 2: Growth-Factor Priority

For each target role, rank the next upgrade source by impact:
- skill / forte levels
- character level / ascension
- weapon level
- echo setup / echo quality

The exact order can vary by role and current state, but the skill must explicitly judge which factor is currently the biggest gain.

## General Growth-Factor Rules

### 1. Fix Major Missing Basics First

If a target role is severely underleveled or using an obviously weak weapon, fix that before fine optimization.

### 2. Skill Priority Is Often Non-Uniform

Do not say "upgrade all skills equally."

Instead:
- identify the highest-impact skill branch first
- mention key examples like burst / forte / intro / outro / transform if relevant
- allow role-specific exceptions

### 3. Weapon Level Can Be A High-Leverage Step

If the role already has the correct weapon but the weapon is underbuilt, weapon level can be one of the fastest power gains.

### 4. Echo Optimization Comes After The Core Spine

Do not push deep echo perfection too early if:
- level is still low
- key skills are underleveled
- weapon is still weak

Echo work should usually begin after the main role skeleton is in place, unless the account is already close to finished basics.

## Output Rule

Every account-specific recommendation should answer both:
- who should be cultivated first
- what aspect of that character should be cultivated first

## Example Reasoning Pattern

Good pattern:
- first build `A/B/C` because they form a current-version top-tier team
- within `A`, the next largest gain comes from skill branch `X`
- after that, bring the character level to the next target breakpoint
- only then spend deeper resources on echo finishing

Bad pattern:
- list many roles without team context
- say "upgrade everything"
- talk about echoes first while core levels and skills are still underbuilt
