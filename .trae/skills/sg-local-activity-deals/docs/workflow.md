# Workflow

## Goal

把“新加坡最近本地活动和优惠”做成稳定可复用的调研闭环，尤其适合：
- 免费活动
- 1-for-1
- 半价
- 限时低价
- 开业活动 / 节庆活动 / 市集活动

## End-to-End Flow

### 1. Define the window

默认时间窗：
- `今天起未来 30 天`

用户若说：
- “最近”
- “这个周末”
- “下周”
- “下个月”

则用用户指定时间窗覆盖默认值。

### 2. Discover on Xiaohongshu

优先搜这些词：
- `新加坡 免费 活动`
- `新加坡 1-for-1`
- `新加坡 半价`
- `新加坡 七月活动`
- `新加坡 八月活动`
- `新加坡 薅羊毛`
- `新加坡 周末活动`

目标不是拿标题，而是：
- 找到合集帖
- 找到具体商家优惠帖
- 找到最近用户真的在讨论的活动

### 3. Read the actual post content

至少点开：
- 2-3 篇合集帖
- 2-3 篇单活动 / 单优惠帖

重点提取：
- 活动时间
- 地点
- 价格
- 优惠条件
- 是否限量
- 是否需要预约 / 注册 / 会员身份

### 4. Split list posts into atomic items

如果一篇笔记里列了 5-10 个活动：
- 必须拆成 5-10 条单独活动
- 每条活动都独立记录

### 5. Cross-check with official pages

优先核验：
- 官方活动页
- 官方票务页
- 官方会员权益页
- 商家菜单 / 商家官网

最少要补：
- 官方确认的时间
- 地点
- 原价 / 折后价 / 折扣方式

### 6. Score confidence

给每条打置信度：
- `高`
- `中高`
- `中`
- `低`

### 7. Produce output

默认顺序：
1. 表格
2. Top 5 最值得冲
3. 免费活动单列
4. 1-for-1 / 半价活动单列

如果用户要 HTML：
- 转成结构化页面
- 支持筛选和标签

## Refresh Rule

后续持续迭代时：
- 优先重跑小红书和官方页
- 保留历史已验证活动
- 把过期活动降级或移除
- 新增活动单独标记 `new`
