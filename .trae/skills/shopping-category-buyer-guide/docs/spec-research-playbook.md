# Spec Research Playbook

## Goal

对归一后的主力型号补齐“足够做决策”的关键参数，而不是追求无限扩表。

## Source Priority

参数核实优先级：
1. 品牌官网 / 官方产品页
2. 官方或自营电商参数页
3. 主流参数库
4. 媒体评测 / 导购
5. 优惠聚合页 / 商品标题

## Research Rule

每个型号先回答两个问题：
- 哪些参数最影响这个品类的体验
- 当前价格对这些参数来说值不值

不同品类的关键参数应不同。

## Example Spec Categories

### 除螨仪

优先看：
- 吸力/功率
- 拍打频率
- 紫外线/热风/超声等杀螨链路
- 尘杯容量
- 过滤系统
- 重量
- 线长或续航
- 噪音

### 电视

优先看：
- 背光类型
- 分区数
- 峰值亮度
- 原生刷新率
- 营销高刷口径
- 内存和存储
- HDMI 2.1
- 低反

### 电饭煲

优先看：
- 加热方式
- 内胆材质
- 容量
- 压力能力
- 菜单/预约/保温能力
- 是否容易清洗

## Conflict Handling

如不同来源冲突：
- 优先更高等级来源
- 保留冲突说明
- 不要把营销口径直接伪装成原生参数

例如：
- `原生刷新率 = 144Hz`
- `营销高刷 = 288Hz`

## Persistence Rule

参数库里至少包含：
- `normalized_model`
- `aliases`
- `key_specs`
- `warnings`
- `confidence`
- `sources`

如果部分参数还没核实：
- 允许先写入部分字段
- 但要把 `status` 标成 `partial_verified`

## Anti-Hallucination Rule

- 未找到稳定来源时写 `null`
- 不要根据系列名自动脑补高配参数
- 不要把相邻型号的参数直接套给目标型号
- 不要只依据电商标题写死全部硬参数
