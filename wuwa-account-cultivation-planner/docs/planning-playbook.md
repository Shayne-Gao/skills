# Planning Playbook

## Objective

Turn a purchased or owned account into a practical cultivation roadmap.

The roadmap should answer:
- what team to play now
- what to raise first
- what can wait
- where the next power jump comes from

## Planning Heuristics

### 0. Start From The Current Version

- First ask which current-version top teams or high-potential key roles deserve first investment.
- Use this order:
  - current-version top-tier teams
  - high-potential key roles, including strong new roles
  - older-version teams
- Do not jump straight into per-character micromanagement before team priority is clear.

### 1. Finish One Good Team First

- Do not spread resources across every owned five-star.
- Prioritize one complete, coherent team before chasing broad coverage.
- If the account already supports a strong complete team, reinforce that team first.

### 2. Retention Matters

- Prefer long-term high-value units already validated in the project role logic.
- Treat `T0/T0.5` preservation as a strong signal for long-term investment.
- Low-retention or filler units should only receive temporary investment unless they unlock a real team breakpoint.

### 3. Weapon Assignment Is Part Of Planning

- A good cultivation plan must pair characters with the best available owned weapons.
- If one carry has clear signature coverage and another does not, the covered carry usually gets priority.
- Mention reassignments explicitly instead of assuming the user will infer them.

### 4. Team Utility Beats Box Score

- A role with lower standalone value may still be priority if it completes the main team.
- Supports that unlock rotation stability, survivability, or full synergy can outrank a side carry.

### 5. Resource Advice Must Be Concrete

- Always translate analysis into an order:
  - first 3 upgrades
  - next 3 upgrades
  - current farming target
  - what not to spend on yet

### 6. Growth-Factor Advice Must Be Ordered

- For each priority role, explicitly state what to improve first:
  - skill / forte
  - character level
  - weapon level
  - echo
- Do not give vague "overall upgrade" advice.
- If possible, mention a rough completion estimate such as `about 80% complete`.

## Suggested Output Format

### Account Read

- current strongest team
- current second-team direction
- main strength
- main weakness

### Upgrade Priority

- priority 1
- priority 2
- priority 3

### Weapon / Echo Notes

- best current weapon assignment
- echo direction by team
- temporary substitutions

### Per-Character Steps

- current state / rough completion
- first upgrade step
- second upgrade step
- third upgrade step

### Farming Focus

- immediate 3-7 day target
- next 2 week target

### Avoid / Delay

- units that should stay low investment for now
- upgrades that look attractive but have weak account impact

## Good Questions To Ask If Needed

Only ask these if the account snapshot is missing them:
- current weapon levels
- current character levels / ascensions
- current forte or talent progress
- current echo sets
- current weekly / daily material bottleneck

## Completion Standard

A planning task is complete when:
- the answer is account-specific
- the advice is phased
- the upgrade order is explicit
- the answer explains both team priority and growth-factor priority
- the user can act on it without reading external theory first
