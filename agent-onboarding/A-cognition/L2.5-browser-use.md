# Lesson 2.5 · 让 Agent 操作浏览器：突破 API 与公开数据的边界

> 一句话定位：当数据在登录态后面、当任务是"重复点点点"、当系统没有 API——**让 Agent 接管你的浏览器**。

---

## 1. 你将学会

- [ ] 我能让 Agent **真的打开一个网页、登录、点击、填写、截图、抓数据**
- [ ] 我能判断哪些任务该走"浏览器操作"、哪些该走"API/CLI"
- [ ] 我能为浏览器操作任务写一份**安全清单**：不让 Agent 误点破坏性按钮

---

## 2. 背景小知识

到 L2 为止，你让 Agent 做的所有事都属于"模型 + 文件系统 + 公开网页搜索"。但 PM 工作里很多场景**不在公开互联网上**：

- 公司后台运营数据：必须登录才能看
- 飞书文档列表 / 多维表格筛选结果：你自己看着比 API 更直观
- 竞品 SaaS 的功能演示：公开页就能点，但要真点一遍才知道交互长什么样
- 各种"重复点 30 次"的体力活：批量下载附件、批量改字段、批量发送邀请

**浏览器操作（Browser Use）就是给 Agent 一个真实浏览器的钥匙**。它能像人一样：
打开网页 → 看到页面截图 → 决定点哪 → 真的点下去 → 看新页面 → 继续……

> 直觉口诀：**没 API 的地方，浏览器就是兜底 API。**

⚠️ 重要前置：浏览器操作 = Agent 真的在你电脑上点击。所以**风险也最大**——它点错按钮和你点错没区别。本讲会专门给你一份"安全清单"。


### Step 2 · 让 Agent 用你已登录的状态进入"我的文档"

**🎯 你要做什么**
进入登录态后的页面。注意：**Agent 不应该让你输入密码**——更安全的姿势是"复用你已登录的浏览器 Profile"，或者你**手动登录后再让 Agent 接管**。

**⌨️ 你输入什么**

```
我会自己手动完成登录（你不要替我输入密码或验证码）。

1) 启动浏览器并打开 https://docs.feishu.cn ，停在登录页
2) 暂停操作，告诉我"已就绪，请你手动登录"
3) 等我说"我登录好了"之后，再继续：
   - 进入"最近"或"我的空间"页
   - 截图存到 pm-agent-lab/browser-lab/screenshots/02-recent.png
   - 告诉我当前页能看到大约多少个文档条目，是否有滚动加载
```

**📝 这一步教会你什么**

- 偏差 B：登录后跳到了"个人版"而不是"企业版" → 让它读 URL 自检：

  ```
  请先 print 出当前页面的 URL 和 title 给我看，确认是不是企业空间。如果不是，停下来问我怎么切。
  ```

**🎯 你要做什么**
让 Agent 把"最近 30 天打开过的文档"提取成结构化数据。

**⌨️ 你输入什么**

```

- 滚动到底加载更多，但只抓最近 30 天内打开的；早于 30 天就停
- 写入：pm-agent-lab/browser-lab/data/recent-docs.json
- 同时给我一段文字汇报：本次共抓 N 条 / 各 type 分布 / 滚动了几次

约束：
1) 不要点开任何文档，只在列表页读取
2) 不要做任何会改数据的操作（不要点收藏/取消收藏/删除）
3) 抓完发我看，不要自动进入下一步
```

### Step 5 · 给浏览器操作上"安全护栏"

> 浏览器操作威力 ≈ 风险。本节做完，把这份清单贴在你 `pm-agent-lab/browser-lab/` 下，以后每次跑浏览器任务前过一遍。

**🎯 你要做什么**
让 Agent 帮你产出 `BROWSER_SAFETY.md`，并且约束以后所有浏览器任务都先读它。

**⌨️ 你输入什么**

```
帮我产出一份 BROWSER_SAFETY.md，存到 pm-agent-lab/browser-lab/BROWSER_SAFETY.md，内容包含：

1) 我永远自己来做的事（凭证、二次验证、支付、点"删除/退订/解散群"按钮）
2) 默认人工确认的操作（任何 POST/PUT/DELETE 类的按钮、群发/邀请、跨域跳转）
3) 你可以独立做的事（只读浏览、滚动、截图、复制文本、点击只读 tab）
4) 出错时的兜底动作（截图存证 → 暂停 → 等我决定）
5) 数据红线（公司机密文档不能上传到外部 LLM 服务做处理；只能在本地处理）

写完后告诉我：以后所有 pm-agent-lab/browser-lab/ 下的浏览器任务，你都要先读这份文档再开始操作。
```

## 9. 给 PM 的小结：浏览器操作的"三问"

任何浏览器任务开始前，先问自己：

1. **有没有 API？** 有就走 API（更稳、更便宜、更安全）。
2. **要不要登录？** 要的话**人工登录 + Agent 接管**，不要把密码喂模型。
3. **会不会改东西？** 会就**默认人工确认**；只读任务再放手让 Agent 自己跑。

这三问做对，浏览器操作就从"高风险炫技"变成"PM 日常工具"。
