# Lesson 4.5 · 多模态：截图 / 设计稿 / 报错图

> 一句话定位：PM 每天处理的图比文字多 10 倍——把 Agent "看图说话"的能力打开，是 ROI 最高的能力升级之一。

---

## 1. 你将学会

- [ ] 我能把竞品截图丢给 Agent，让它**逐元素拆解 UI 与文案**
- [ ] 我能让 Agent **对比两版设计稿**并自动写"改稿说明"
- [ ] 我能把研发或读者发来的**报错截图**直接交给 Agent 解读

---

## 2. 背景小知识

到 L4 你已经会"喂文字"。但你看：

- 竞品同事甩来一张图：".png 放群里了，看一眼？"
- 设计师改稿：3 张稿子飞过来，让你说"哪版好"
- 研发 / 客服报问题：截一张报错图

这些场景，**文字描述能力都是次优解**——直接喂图最快。**多模态**就是：Agent 不仅能读文字，还能读图，甚至读 PDF / 视频帧 / 音频。

> 直觉口诀：**能截图就别打字。**
> 你的眼睛已经看到了——让 Agent 也"看到"，比你转译一遍快 10 倍。

⚠️ 红线：图里如果有用户隐私 / 公司机密数字 / 未公开人脸——**先脱敏**再喂模型，特别是外部模型。

### Step 1 · 让 Agent 拆解一张竞品截图

**🎯 你要做什么**
把一张竞品页面截图扔进去，让 Agent 像产品分析师一样拆解。

**⌨️ 你输入什么**（同时附上截图）

```
[附图：竞品某页面截图]

[角色] 你是资深 PM，正在做竞品分析。

[上下文] 这是 <竞品名> 的 <页面名> 截图。我想看清楚他们在这个页面想做什么。

[约束]
- 只描述图里真实存在的元素，不要脑补图外的功能
- 找不清楚的元素直接说"看不清"
- 不要写"建议我们也做"这种空话；我自己来判断

[产物]
请输出到 pm-agent-lab/vision-lab/competitor-<竞品名>-<页面名>.md，分 4 段：
1) 页面信息架构（顶到底各模块）
2) 每个 CTA 按钮的文案 + 视觉权重排序
3) 核心数据/卖点的呈现方式（颜色、留白、字号优先级）
4) 你能从布局推断出的"核心目标动作"是什么（不超过 1 句话）
```

**👀 预期看到什么**
- 一份非常具体的拆解，比你"用眼睛过一遍"细很多

**⚠️ 如果出错怎么办**
- 偏差 A：Agent 开始猜未在图里的功能 → 纠偏：

  ```
  你刚才提到"应该还有筛选功能"——图里没有。请只描述图里真实存在的元素，没看到的写"未在截图中"。
  ```

- 偏差 B：图太糊 / 字看不清 → 让它老实承认：

  ```
  哪些元素你看不清？列出来，让我决定要不要重新截图。
  ```

### Step 2 · 让 Agent 写"改稿对比说明"

> 这是 PM 高频场景：设计师给两版稿，你要发同步说"改了什么、为什么、是否同意"。

**🎯 你要做什么**
喂两张设计稿（旧版 + 新版），让 Agent 自动出对比说明。

**⌨️ 你输入什么**（附两张图）

```
[附图 1：旧版设计稿 v1]
[附图 2：新版设计稿 v2]

[角色] 你是产品经理，正在为设计改版写一份对比说明，发给跨职能同事看。

[上下文] 这两张是同一页面的旧版（v1）和新版（v2）。我没告诉你设计师为什么改，请你自己从图里推断。

[约束]
- 客观描述变更，不要过早评价好坏
- 每个变更点写 3 行：变了什么 / 推断意图 / 我作为 PM 应该追问设计的 1 个问题
- 改动不到 5 处也老实说，不要凑数

[产物]
写到 pm-agent-lab/vision-lab/design-diff.md，结构：
- 总览（一句话：本次改版核心方向是什么）
- 变更点 1..N（每点 3 行）
- 待与设计确认的 3 个最关键问题
```

- 给我"我作为 PM 该跟谁同步、该问什么"3 条建议

### Step 5 · 进阶：PDF / 长截图 / 多张图的"看图打包"

PM 偶尔会遇到这些情况，提前给你 prompt 备着：

#### 5.1 长截图（一张超长图）

```
我贴一张超长截图（产品全屏滚动），请：
1) 先按视觉分块（顶部导航 / 主 banner / 模块 1..N / 页脚），列出分块
2) 我说"展开模块 X"，你再细拆
不要一次性把所有模块都细拆，否则太长。
```

#### 5.2 PDF 报告（行业研报 / 招股书）

```
我上传一份 PDF：
1) 先给我目录（每章 1 行 + 页码）
2) 我说"读第 X 章"，你才读取并总结
3) 总结时区分"原文事实"和"你的推断"
不要一上来就把整份 PDF 都读完。
```

#### 5.3 多张图（用户访谈截图集）

```
我会陆续贴 N 张用户反馈截图。每张你只做：
1) 提取文字
2) 打标签（性能 / 体验 / 价格 / 其它）
全部贴完我说"开始聚类"，你才合并分析。这样不会信息过载。
```

## 8. 副线练习（可选）

本讲主线已可在三个场景切换，副线建议挑战更进阶的玩法：

- **用户访谈视频整理**：把一段短视频或会议录屏的关键帧截 5–10 张丢给 Agent，让它提炼用户原话和情绪曲线
- **白板照片转 PRD 大纲**：把会议室白板拍下来扔给 Agent，让它直接转成 PRD 草稿目录
- **Excel/表格截图 → JSON**：把领导发你的截图表格让 Agent 反向 OCR 成 JSON，方便下游处理

## 9. 给 PM 的小结：图的"四类用法"

| 用法 | 典型动作 | 关键 prompt 词 |
|------|----------|------------------|
| **拆解** | 把图变成结构化文字 | "逐模块描述" / "列出 CTA 文案与视觉权重" |
| **对比** | 多张图找差异 | "变了什么 / 推断意图 / 应追问的问题" |
| **解读** | 把图翻译给不同受众 | "翻译成非技术语言 / 给同步建议" |
| **反向构造** | 从图反推产物 | "把白板转成 PRD 目录 / 把表格图转 JSON" |

记住这四类，**90% 的 PM 看图场景都能套上 Agent**。
