# 最小词表 · 5 个词建立 Agent 直觉

> 本课程不追求术语精确，只追求**直觉到位**。读完这 5 条，你就能开始 L0。
> 进阶解释会在对应的课程里按需展开，不必现在搞懂全部。

---

## 1. Agent（智能体）

**一句话**：能自己"看-想-做-再看"的 LLM。

**对比 Chat**：
- Chat：你问一句，它答一句。
- Agent：你给一个目标，它会**主动调用工具**（搜网、读文件、写文件、跑命令）、看到结果后再决定下一步，直到目标完成或卡住。

**PM 直觉**：把 Agent 当成一个"非常听话但需要你把目标讲清楚的实习生"。

---

## 2. Tool（工具）

**一句话**：Agent 的"手脚"——任何它可以调用来产生副作用或获取信息的能力。

**常见 Tool 类型**：
- 读写本地文件（`Read` / `Write` / `Edit`）
- 搜索网页 / 抓取网页
- 执行终端命令（`RunCommand`）
- 调企业 API（飞书 / 内部系统 / lark-cli ...）

**PM 直觉**：模型本身只会"想"，**真正能"做事"全靠 Tool**。一个 Agent 强不强，很大程度看它接了多少 Tool。

---

## 3. Skill（技能 / 工作流封装）

**一句话**：把"提示词 + 步骤 + 约束 + 产物路径"打包，让 Agent 下次能稳定复现的一段流程。

**举例**：
- 一次性 prompt："帮我调研一下 AI Agent 行业新闻"——这是**临时**。
- Skill `news-weekly`：触发词、关键词输入、调研步骤、落盘路径、HTML 模板、摘要风格——这是**资产**。

**PM 直觉**：Skill 之于 Agent，就像 SOP 之于团队。**Skill 才是 Agent 时代真正可累积的生产资料**。

---

## 4. Context（上下文）

**一句话**：Agent 这一次回答时"能看到的所有信息"。

**包含**：
- 你的 prompt
- 之前对话历史
- Agent 自己读到的文件 / 网页 / 工具返回结果
- 系统给它注入的规则（项目 `AGENTS.md`、记忆等）

**核心痛点**：Context 是有限的（有"窗口"上限），所以会遗忘、会被挤掉。

**PM 直觉**：当你觉得 Agent "变笨了 / 忘事了"，多半不是模型差，而是**上下文管理不好**。L4 会教你怎么解决。

---

## 5. RAG / LLM Wiki（检索增强 / 个人知识库）

**一句话**：让 Agent **每次回答前先去一个外部知识库里查一下**，再结合查到的内容作答。

**为什么要它**：
- 模型不知道你公司的事
- 模型记不住你过往所有对话
- 你不想每次都把同一段背景粘贴一遍

**PM 直觉**：与其每次都给 Agent 讲"我们产品是干啥的"，不如把这些信息一次性写进 `llm-wiki/`，让 Agent 自己去查。L4 会带你建一个最简版。

| 词 | 大概是啥 | 何时再看 |
|----|----------|----------|
| MCP | 一种让 Agent 接入外部工具的标准协议 | L6 / L8 |
| Plan Mode / Spec Mode | 让 Agent 先规划再执行的工作模式 | L9 |
| Human-in-the-loop | 人在环路：关键步骤插入人工确认 | L10 |
| Eval | 评估 Agent 输出质量的方法 | L11 之后 |
| Multi-Agent | 多个 Agent 协同分工 | 进阶选读，本课不展开 |
