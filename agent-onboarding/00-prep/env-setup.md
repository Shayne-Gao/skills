# 准备工作 · 环境与目录清单

> 本课程主线产物全部落在你本地，所以**先把环境和目录准备好**，后续每一讲不再重复说明。
> 全部完成约需 20–40 分钟（取决于 lark-cli 是否之前装过）。

---

## 1. 选定一款 Agent 客户端（必选）

任选其一，公司允许即可。本手册的 prompt 在三者上都验证过：

| 客户端 | 适合谁 | 备注 |
|--------|--------|------|
| **Codex / ChatGPT Agent Mode** | 对终端不熟、希望开箱即用 | 入门最丝滑 |
| **Claude Code** | 喜欢命令行、要操作较多本地文件 | Skill 体系最成熟 |
| **Trae（公司内部）** | 字节同事 | 集成度高、安全合规 |

> 后续讲义中所有 prompt 都直接给原文，不依赖某一款客户端的特殊语法。

---

## 2. 工作目录（必选）

在你常用的工作盘下，建一个空目录作为整门课的**根**：

```
pm-agent-lab/
```

**强烈建议**：把它放在你日常会备份的位置（iCloud / OneDrive / 公司云盘任选），避免重装电脑后产物全丢。

接下来每一讲都会在 `pm-agent-lab/` 下新增子目录，不要把它和其它项目混在一起。

---

## 3. 飞书 lark-cli（C 篇章必选，A/B 篇章不强制）

C 篇章（L6–L9）会大量使用飞书原生能力（doc / sheets / im / calendar / base / wiki）。如果你只想体验 A/B 篇章，可以先跳过本节。

**最小安装步骤**（详细见公司内 lark-cli 文档）：

1. 按公司内文档安装 `lark-cli`
2. 第一次使用前执行：`lark-cli config init`
3. 登录授权：`lark-cli auth login`
4. 验证：随便跑一个只读命令，例如查一下今天的日程

> 遇到 `Permission denied` 几乎都是 scope 不全；按提示加 scope、重新授权即可。

## 5. 常见踩坑

| 现象 | 多半原因 | 处理 |
|------|----------|------|
| Agent 一直说"我无法访问外网" | 客户端没开联网 / 没装 web 工具 | 切到带联网能力的模式 |
| Agent 说"我没有权限写入文件" | 客户端在受限模式 | 启用"允许读写本地文件"权限 |
| 同样的 prompt 结果差异很大 | 上下文不一致 / 模型随机性 | 把 prompt 写得更精确（L3 会教） |
| lark-cli 报 `Permission denied` | scope 不全 | 重新跑 `auth login` 并加上提示的 scope |
