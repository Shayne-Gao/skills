# Lesson 12 · 自我进化：找出你工作中的 10 个 Agent 机会

> 一句话定位：把这本手册学到的所有能力，**变成你工作里持续被使用的"机会清单"**——这是整个旅程的最后一公里。

---

## 1. 你将学会

- [ ] 我能从自己**真实的一周日历 / 文档 / 群聊**里挖出 ≥ 10 个 Agent 可介入的任务
- [ ] 我能用"频率 × 痛苦度 × 可沉淀性"给这些机会**打分排序**，决定先做哪几个
- [ ] 我能产出一份"**我的 Agent 机会清单 v1**"，并写出**未来 30 天行动计划**

---

## 2. 背景小知识

到这里你已经具备 Agent 时代 PM 的全部基础动作：上下文（L4）、Prompt（L3）、多模态（L4.5）、Skill（L5/L11）、企业接入（L6–L9）、边界（L10）。

但很多人学完工具之后回到工位，**并不会真的用起来**。原因只有一个：

> **没有把"我自己的工作"和"Agent 能做的事"做一次系统性的对照。**

L12 要补的就是这一步。我们不再学新工具，而是把焦点反过来——**审视你自己的一周**。

挖掘机会的三把尺子：

| 尺子 | 含义 | 给出的信号 |
|------|------|-----------|
| **频率 F** | 这件事多久做一次 | 周/月级高频 → 沉淀 ROI 高 |
| **痛苦度 P** | 做这件事时你是不是很烦/很累/很重复 | 越烦越值得让 Agent 接 |
| **可沉淀性 S** | 流程是否清晰、产物是否结构化 | 越清晰越容易 Skill 化 |

> 直觉口诀：**高频 × 高痛 × 可沉淀 = Skill 候选。** 一次性、不痛、流程不清的——别动它，别勉强 Agent 化。

⚠️ 反模式：
- 一上来挑"看起来最酷"的任务（比如自动写 PRD 全文）→ 通常是**高难度低 ROI**
- 只挑自己舒适区的任务 → 杠杆小
- 一次想做 10 个 Skill → 哪个都做不完

### Step 1 · 把"你的一周"喂给 Agent

**🎯 你要做什么**
导出最近一周真实工作素材，让 Agent 先有上下文，再开始挖。

**⌨️ 你输入什么**

```
我要做一次"我的工作 Agent 机会盘点"。请你扮演一位资深 PM 工作流教练。

我会贴/发以下材料给你，你先只做"接收+理解"，不要急着给建议：

[1] 最近一周的日历（我会贴文字版或截图）
[2] 我最近 10 篇飞书文档的标题列表
[3] 我每天大概在哪些群里花时间，分别在干什么
[4] 我最近一次觉得"特别烦/特别耗时"的 3 件具体事情（详细描述）

请你接收完后，先用一段不超过 200 字的话向我"复述"你看到的我的工作画像，
确认无误后再进入下一步。如果你看到信息不够，主动问我最多 3 个问题。
```

### Step 3 · 用三把尺子打分排序

**🎯 你要做什么**
按 F × P × S 把候选机会排序，**砍掉低分长尾**。

**⌨️ 你输入什么**

```
基于 opportunities-v1.md，做以下处理：

1) 计算每条机会的总分 = F × P × S（满分 125）
2) 按总分倒序排列
3) 输出三档：
   - 🔥 第一梯队（总分 ≥ 60）：3 个月内必须做掉
   - ⚙️ 第二梯队（30 ≤ 总分 < 60）：未来半年视情况做
   - 🧊 暂缓区（< 30）：明确写"暂不做"的原因，避免以后又被反复拿出来评估
4) 第一梯队每条额外补充：
   - 用本手册哪些讲学到的能力可以直接落地（如 L5 Skill 化 / L9 端到端工作流）
   - 第一步 prompt 应该长什么样（直接给原文，不要写"类似这样"）
   - 是否需要团队 Skill（L11）化，还是先自己用

把完整结果写到 pm-agent-lab/self-evolution/opportunities-ranked.md。
```

```
3) 每周给出"3 件具体动作 + 1 个反思问题"
4) 给我一份"放弃信号"：什么情况下我应该停下来，不再勉强这条机会
5) 末尾留一段"复盘锚点"：30 天后我应该回头看哪 5 个指标（如：纪要处理频次、待办按期完成率、跨部门同步耗时）

写到 pm-agent-lab/self-evolution/30-day-plan.md。
最后给我一段 100 字以内的"自我承诺"草稿，我会贴在我桌面上。
```
</details>

## 6. 思考题 & 收尾

**思考题**
- 如果你身边的 PM 同事都不用 Agent，你愿意当那个"先跑出来"的人吗？为什么愿意 / 为什么不愿意？
- 半年后回头看这份机会清单，你最希望看到的"成功画面"是什么？把它写下来——这就是你真正的目标。
- L0–L12 走完，你觉得 PM 这个岗位**最不可替代的部分**是什么？哪些反而是 Agent 该接走的？

**没有"下一讲"了**
但这本手册希望你接下来做三件事：

1. **本周内**：把 30 天计划的第一条跑通，不论多小。
2. **本月内**：找一位同事一起做一遍 L11，把你的某个 Skill 团队化。
3. **本季度内**：再跑一次 `quarterly-self-evolution`——你会真切看到自己在变。

## 8. 副线练习（可选 · 把方法迁移出去）

> 本讲主线已可在三个场景切换，副线建议挑战更进阶的玩法。

- **给团队做一次**：用同样四步，对你的小组做一次"团队 Agent 机会盘点"，输出团队版 opportunities。
- **给自己做"反向清单"**：除了"哪些可以让 Agent 做"，再列一份"哪些**绝对不交给 Agent**"——比如和人建立信任、跨团队推动、判断价值取舍。这份清单是你作为 PM 的护城河。
- **用 Agent 写一封信给 3 个月后的自己**：把今天的 30 天计划、暂缓区、自我承诺都喂给它，让它在 90 天后自动提醒你回看。

## 9. 给 PM 的最后一句口诀

| 阶段 | 标志 |
|------|------|
| 听说过 | 知道 Agent 是什么 |
| 用起来 | 会让 Agent 替你做某件具体的事（L1–L5） |
