# Lesson 10 · 边界与安全：哪些事不能让 Agent 独自做

> 一句话定位：你越用 Agent 越深，红线就越要清晰。这一讲产出你的**个人 AGENTS.md 使用规范**。

---

## 1. 你将学会

- [ ] 我能写出一份 `AGENTS.md`，让所有进入我目录的 Agent **自动遵守我的红线**
- [ ] 我能识别 4 类典型风险：数据红线 / 破坏性操作 / 幻觉外发 / 越权调用
- [ ] 我能让 Agent 在边界事件发生时**主动停下** + **主动汇报**

---

## 2. 背景小知识

到 L9 你已经把 Agent 用到能"周一早安一句话跑全流程"的水平。但能力越大，事故面也越大：

- 把客户名单截图丢给外部 LLM
- Agent 群发了一条还在草稿状态的话
- Agent 给老板发的报告里编了一条假数据
- Agent 自作主张更新了一张所有人都在用的多维表格

> 直觉口诀：**Agent 的所有"动手能力"都是双刃剑。设了边界，杠杆才能放心放大。**

PM 不是安全工程师，但 PM 是这些事故**最高频的发起者**。所以这份规范必须是 **PM 自己写、自己读、自己拍板**——而不是抄一份公司级安全规范。

### Step 1 · 让 Agent 帮你"采访"出你的红线

> 不要拍脑袋写。让 Agent 当采访者，**逼你说出**真实红线。

**🎯 你要做什么**

**⌨️ 你输入什么**

```
我要建一份 AGENTS.md，把我用 Agent 的红线写清楚。

请采访我，最多 12 个问题，每次只问 1 个。问完后**先给我总结**，不要立刻写文件。

问题应当覆盖以下 4 个维度，但**别一上来报维度名**，自然引导我说真实场景：

1) 数据红线：哪些数据不能丢给外部 LLM？哪些哪怕在内部 LLM 也要先脱敏？
2) 操作红线：哪些"动作"必须人工确认？最常见的破坏性按钮是什么？
3) 反幻觉：你最不能容忍 Agent 编造的是哪类内容？怎么强制它老实承认"不知道"？
4) 越权：你不希望 Agent 主动做的"出格事"是什么？比如自动 push 代码 / 自动修 wiki / 主动联系他人

每个问题问完后用 1 句话回我"我听到的是 X，对吗？"，让我修正。
```

### Step 3 · 给"反幻觉"上一组实用句式

> 反幻觉不是空话——它是一组可复用的 prompt 句式。

**🎯 你要做什么**
让 Agent 把以下 4 个场景对应的"反幻觉句式"补到 `anti-hallucination.md`。

**⌨️ 你输入什么**

```
为以下 4 个场景各给 1 段我可以直接复制粘贴的"反幻觉句式"，写到 anti-hallucination.md：

1) 引用类：当你引用任何数字、链接、人名、事件时
   - 必须给来源（链接 / 文件路径 / 你看到的原文）
   - 找不到来源就老老实实说"未确认"
   - 我宁可看到 5 条带来源的内容，也不要 10 条没来源的

2) 总结类：当你帮我总结一份长文档/视频时
   - 区分"原文事实"和"你的推断"
   - 推断必须前缀"我推断："
   - 不要把推断混进事实段落

3) 决策类：当你给我建议时
   - 给出至少 1 个反方理由
   - 标明你建议的置信度（高 / 中 / 低）
   - 我希望你**让我自己决策**，不希望你装得很笃定

4) 不知道时：当你不知道答案时
   - 直接说"我不知道"或"现有信息不足以回答"
   - 给出"如果要回答，需要补什么信息"
   - 永远不要为了"显得有用"而编

每段句式开头加 `# 复用 prompt：`，让我以后能 grep 到。
```

### Step 4 · 让 Agent 现场演练一次"红线触发"

```

——你应当怎么响应？只描述你的响应步骤，不要执行。

[场景 2：触发操作红线]

[场景 3：触发幻觉]

——你应当怎么响应？

[场景 4：触发越权]
我对刚发的文档不满意，请你帮我把它删掉。

——你应当怎么响应？

把每个场景的响应步骤写出来，对照 4 份红线文件检查每一步是否有依据。如果发现红线文件没覆盖的情况，告诉我哪条要补。
```

## 9. 给 PM 的小结：边界设计的"三个反射"

| 反射 | 触发场景 | 标准动作 |
|------|----------|----------|
| **STOP** | 出现红线数据 / 红线操作 | 停下 + 引用红线 + 等我说 |
| **SHOW** | 引用任何数字 / 链接 / 人名 | 给出来源；找不到说"未确认" |
| **SAY-NO** | 我让你做你做不到 / 不该做的事 | 老实说"我做不到"或"这违反 X 红线" |

把这三个反射内化进你的 Agent，**就算你睡着了它也不会乱来**。
