# Source Priority

## Priority Order

### Tier 1 — Official

最高优先级：
- 官方活动页
- 官方票务页
- 官方会员权益页
- 商家官网 / 商家菜单页

用途：
- 核时间
- 核地点
- 核价格
- 核活动规则

### Tier 2 — Social Discovery

第二优先级：
- 小红书正文
- B站视频描述 / 视频标题
- 社媒活动攻略帖

用途：
- 发现线索
- 补中文语境
- 补用户视角
- 补“到底值不值得去”

## Xiaohongshu Rules

### Good signals

更可信的小红书正文通常有：
- 明确日期
- 明确门店 / 地点
- 明确价格
- 明确活动条件
- 明确“几点去 / 是否限量 / 是否预约”

### Weak signals

较弱的小红书内容：
- 只写“很值”“快冲”
- 只写“便宜哭了”
- 没写时间和地点
- 没写参与条件

### Required handling

对小红书内容必须：
- 尽量读正文
- 保存原帖链接
- 说明是“正文写了什么”

## Bilibili Rules

B站更适合：
- 活动攻略
- 场地解释
- 视频型体验内容

不适合单独作为价格证据。

如果 B 站里提到折扣：
- 必须尽量去官网补价格

## Platform Coupon Rules

Klook / Trip / OTA / 平台券处理原则：
- 明确标记 `平台券`
- 不要标成 `官方折扣`
- 可以作为补充省钱方式
- 需要提醒用户下单前验证

## Confidence Mapping

- `高`
  - 官方页直出
  - 时间和价格明确
- `中高`
  - 小红书正文具体
  - 官网页面能核到部分关键信息
- `中`
  - 社媒较具体
  - 但缺一部分关键条件
- `低`
  - 只有社媒线索
  - 无法确认
