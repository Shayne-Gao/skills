# Output Spec

## Default Table

默认表格字段建议：

| 活动 | 中文说明 | 活动类型 | 时间 | 地点 | 优惠方式 | 原价 | 折后/现价 | 小红书正文说了什么 | 官方/补充说明 | 置信度 | 链接 |

## Shortlist Table

如果用户要“最值得冲”的版本，可用：

| 活动 | 为什么值得冲 | 价格亮点 | 限制条件 | 链接 |

## HTML Required Fields

如果输出 HTML，建议每条卡片至少有：
- 中文标题
- 英文原名
- 活动类型
- 免费 / 1-for-1 / 半价 / 平台券标签
- 时间
- 地点
- 原价
- 折后价
- 小红书原帖链接
- 官方页链接
- 置信度

## Formatting Preference

根据当前用户偏好，输出时：
- 重点项可使用 `**加粗**`
- 真正的羊毛项可使用 `<u>下划线</u>`
- 优先用表格，不要只写散文式总结

## Special Cases

### 1-for-1

尽量额外写：
- 单件原价
- 双人总价
- 人均价格

### 免费活动

写清楚：
- 是完全免费
- 还是免费入场但内部消费自理
- 是否需要预约 / 抢名额

### 半价 / 折扣

尽量写成：
- `原价 -> 折后价`
- 如果没有价格，只能写：
  - `50% off`
  - `20% off`

### 合集帖拆解

如果一篇小红书正文里提到多个活动：
- 每个活动都单列
- 链接可重复指向同一篇原帖

## Summary Block

在表格后，建议补一个简短总结：
- `最值得冲 Top 5`
- `纯免费`
- `真 1-for-1 / 真半价`
- `需要尽快抢名额`
