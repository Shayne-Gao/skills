# Workflow

## Goal

在 `workspace_projects/spider_smzdm/` 内执行一轮“默认 `3+5` 最新内容抓取 + 全量落盘 + 历史比价 + Top20 推荐”。

当前推荐逻辑强调：
- `SMZDM 平台标签 / 信息标签` 优先
- `值 / 不值` 票数第二
- 门槛、去噪和品类常识第三
- 本地历史价格验证第四
- 商品自身活动标签最后浅看

## Inputs

默认输入：
- `jingxuan_pages = 3`
- `faxian_pages = 5`

可选输入：
- 用户指定更多页数
- 用户指定只看某一池
- 用户指定只做落盘、不做推荐

## Steps

1. 确认抓取窗口
2. 逐页抓取最新商品字段
3. 同时拆分 `SMZDM 平台标签` 与 `商品自身活动标签`
4. 记录 `值 / 不值` 票数
5. 先落盘当前页结果，再继续下一页
6. 写入本轮 capture 目录
7. 汇总本轮页数和条数
8. 读取历史 capture 做同款/近似款对比
9. 生成推荐结果与 Top20

## Historical Comparison

优先级：
1. 同 `link`
2. 标准化标题近似匹配

输出建议对比字段：
- 本次价格
- 最近一次历史价格
- 历史最低价
- 首次出现时间
- 最近出现时间
- 出现次数
- 页面历史型标签
- 历史结论是否与页面标签一致

## Recommendation Order

生成 Top20 时按如下顺序打分或排序：

1. `SMZDM 平台标签 / 信息标签`
- 标题标签：`绝对值`
- 标题标签：`今日必买`
- 标题标签：`手慢无`
- 标题标签：`值友专享`
- 信息标签：`xx天新低`
- 信息标签：`比上次发布低xx%`
- 信息标签：`价格低于618`
- 信息标签：`低于常卖价`
- 辅助标签：`热度Top`
- 辅助标签：`商品好评率`

2. `社区反馈`
- `值 / 不值` 总票数
- `值率`
- 票数太少时只做弱参考

3. `门槛与去噪`
- `需买N件`
- `需用券`
- `会员`
- `淘金币`
- `多人团`
- `过期`
- 高价护肤礼盒、服饰噪音、信息不清晰条目

4. `本地历史验证`
- 优先按 `link`
- 再按标准化标题
- 如果当前价明显高于本地历史，说明不划算，应降权或排除
- 如果当前价低于本地历史，或本地没有样本，只能说明“没有明显负面证据”，不能当成强正向理由

5. `商品自身活动标签`
- `百亿补贴`
- `88VIP`
- `PLUS会员`
- `国家补贴`
- `淘金币`

## Delivery Format

每次都先输出：
- 看了多少页
- 抓了多少行

然后输出：
- `紧凑版` Top20 推荐表

默认表头固定为：

```text
商品 | 价格 | SMZDM信号 | 值率 | 门槛 | 历史
```

各列含义：
- `商品`
  - 商品标题可点击
  - 平台直接并入商品列，而不是单独占一列
- `价格`
  - 保留原始价格文本
- `SMZDM信号`
  - 只保留最关键的 `2-3` 个平台信号，避免表格过宽
- `值率`
  - 统一格式：`值/不值 (百分比)`
- `门槛`
  - 用短词压缩，如 `单买`、`用券`、`88VIP`、`PLUS`
- `历史`
  - 用短结论压缩，如 `无样本`
  - 或 `link 2条，最近/最低 2.93`
  - 或 `比本地历史贵`

不要默认输出过宽表格，如：
- 单独拆 `平台` 一列
- 单独拆 `值` / `不值` / `值率` 三列
- 在 `历史` 列中展开过长说明

## Failure Handling

- 如某页抓取失败，保留已抓到页面并继续写 summary
- 如遇风控页或安全验证，停止扩大抓取范围
- 如历史样本不足，明确标注而不是强行判断低价
